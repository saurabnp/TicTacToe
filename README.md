# 🎮 Tic Tac Toe Game (C++)

A simple, interactive **Tic Tac Toe** game written in C++. This is a console-based two-player game that allows users to play turn-by-turn and announces the winner or a draw at the end. Great for beginners to learn game logic, user input handling, and basic OOP in C++.

---

## 🚀 Features

- Two-player turn-based gameplay.
- Input validation to prevent overwriting filled cells.
- Instant result display (win/draw).
- Simple UI using console output.
- Beginner-friendly code with modular structure.
- 🧱 **Object-Oriented Programming (OOP)** design using classes and encapsulation.

---

## 🧠 Game Rules

- Played on a 3x3 grid.
- Player 1 uses `X`, Player 2 uses `O`.
- Players alternate turns placing their marks on an empty cell.
- First to align 3 marks in a row (horizontally, vertically, or diagonally) wins.
- If all cells are filled with no winner, the game ends in a draw.

🛠️ How to Run
1. Clone the repository:
```bash
git clone https://github.com/yourusername/tictactoe.git
cd tictactoe
```
2. Compile the code :
```bash
g++ -o tictactoe tictactoe.cpp
```
3. Run the .exe file:
```bash
./tictactoe    # On Linux/Mac
tictactoe.exe  # On Windows
```

👨‍🏫 Concepts Used
✅ Object-Oriented Programming (OOP): The game logic is encapsulated inside a tictactoe class.

✅ Clean separation of responsibilities via class methods.

✅ Arrays for board and position tracking.

✅ Condition checks for win/draw scenarios.
